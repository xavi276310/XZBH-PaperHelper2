# 论文写作助手 · 箫张跋扈

一个基于 Streamlit 的学术写作提示词工具，包含“学术写作提示词”和“关于作者”两个页面。

## 启动

建议使用 Python 3.9 或更高版本。在解压后的项目目录中打开终端，执行：

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

打开终端显示的本地地址即可使用；关闭终端中的进程可停止应用。

## 使用方法

1. 选择分类，或搜索中文、英文关键词。
2. 点击一个提示词，在右侧替换占位内容、按需编辑，然后按 Ctrl+Enter 应用修改。
3. 点击“复制提示词”，粘贴到你使用的 AI 工具中。
4. 如浏览器限制剪贴板权限，可在文本框全选复制，或点击“下载 TXT”。

页面保留 48 个提示词、7 类场景。编辑草稿仅在本次浏览器会话中保留，不会写入原始模板；刷新、断开或重启后不保证保留。需要长期保存时请下载 TXT。“恢复原始模板”只重置当前提示词的草稿。

本项目提供提示词模板，不直接调用模型 API。使用时需在其他 AI 工具中完成对话。

## 文件结构

- `app.py`：入口与侧边栏导航。
- `config.py`：应用配置与资源路径。
- `catalog.py`：分类、数据读取与搜索。
- `ui.py`：公共样式与复制组件。
- `views/`：提示词页与作者页。
- `data/prompts.json`：全部提示词。
- `tupian.jpg`：原有作者资源图片。
- `.streamlit/config.toml`：界面主题。

修改提示词正文可编辑 `data/prompts.json`；增加或删除提示词时，需同步维护 `catalog.py` 中的分类列表。
